# React Product Management Dashboard

A practice project for:
- Callback Functions
- First-Class Functions
- Higher-Order Functions
- Closures
- IIFE
- Pure and Impure Functions
- Function Composition

## Run the project

```bash
npm install
npm run dev
```

## Concepts used

- Callback: `onAddToCart`, `onRemove`, `onIncrease`, `onDecrease`
- First-class functions: event handlers are stored in variables and passed as props
- Higher-order functions: `map`, `filter`, `reduce`
- Closures: React handlers access state from their component render scope
- IIFE: welcome message is calculated immediately
- Pure functions: utility functions return new values without mutating input
- Function composition: product names are cleaned and formatted through small functions
