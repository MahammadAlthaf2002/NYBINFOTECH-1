# RouteHub - React Router Practice Project

## Concepts used
- BrowserRouter
- Routes and Route
- Static routing
- Dynamic routing with `/products/:id`
- `useParams`
- `Link`
- `NavLink` and active styling
- `useNavigate`
- Nested routes
- `Outlet`
- Protected routes
- `Navigate`
- 404 route with `path="*"`
- Multiple reusable components

## Run
```bash
npm install
npm run dev
```

## Important routes
- `/`
- `/products`
- `/products/1`
- `/products/2`
- `/about`
- `/login`
- `/dashboard`
- `/dashboard/profile`
- `/dashboard/settings`
- Any invalid URL -> 404
