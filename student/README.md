# Student Result Manager

A very small JavaScript mini project for practicing array methods.

## Concepts Used

- Array creation and accessing elements
- map()
- filter()
- reduce()
- find()
- findIndex()
- some()
- every()
- sort()
- Set for removing duplicates

## How to Run

Open `index.html` in a browser.
