# ES6+ Revision - Mini Task Manager

A small vanilla JavaScript project designed for ES6+ revision.

## Concepts covered

1. ES6+ features and arrow functions
2. JavaScript Modules (`import` / `export`)
3. Optional Chaining (`?.`)
4. Nullish Coalescing (`??`)
5. Spread and Rest (`...`)
6. Destructuring
7. Template Literals
8. Map
9. WeakMap
10. WeakSet
11. `const` / `let`
12. Array methods: `map`, `filter`, `forEach`
13. DOM events
14. Form handling
15. Search/filter functionality

## How to run

Because this project uses JavaScript modules, open it through a local server.

### Option 1: VS Code
Install the Live Server extension and open `index.html` with Live Server.

### Option 2: Node
From the project folder run:

```bash
npx serve .
```

Then open the local URL shown in the terminal.

## Project flow

- Add tasks from the form.
- Mark tasks as completed.
- Delete tasks.
- Search tasks.
- Clear completed tasks.
- Open the browser console to see Map, WeakMap, WeakSet, optional chaining, nullish coalescing, spread/rest, destructuring and template-literal examples.

## Suggested practice

After understanding the project, try adding:
- Priority using destructuring.
- A `Set` for unique categories.
- LocalStorage.
- Edit-task functionality.
- Sorting by category.
