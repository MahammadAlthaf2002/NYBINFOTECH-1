# JavaScript Prototype & Classes — Combined Practice Project

This project combines:
- Prototype
- Prototype Chain
- `prototype`
- `__proto__`
- Constructor Functions
- Classes
- Constructor
- Methods
- Inheritance
- Encapsulation
- `extends`
- `super`

## Run
Open `index.html` in a browser.

The project demonstrates the concepts using a simple Bank Account example.
See `index.html` for the interactive demo and `script.js` for all examples.
