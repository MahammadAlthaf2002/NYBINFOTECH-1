# Chennai Energy

A small JavaScript project for practicing asynchronous JavaScript.

### Concepts covered
- Call Stack
- Web APIs
- Event Loop
- Microtask Queue
- Macrotask Queue
- Execution Order
- Promises
- Async/Await

### Run
Open `index.html` in a browser.

### Project idea
The page displays a simple energy reading. Refreshing the reading uses a Promise and `setTimeout` to simulate an API request. The Event Loop demo shows why synchronous code runs first, Promise microtasks run next, and timer callbacks run afterward.
